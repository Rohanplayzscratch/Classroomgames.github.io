👨‍💻 Want Your Game Here?

Anyone can submit a game!

  1. Create your game in Scratch, HTML, JavaScript, Python (compiled for web), or another web-compatible format.
  2. Export it as HTML if needed.
  3. Send the game and preview image to the Classroom Games team.
  4. We'll review it and add it to the website.

Every published game includes:

  • 🎮 Game page
  • 👤 Creator credit
  • 🖼 Preview image
  • 📝 Description
  • ⭐ Difficulty rating
